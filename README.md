# Gardener Adventure: Vine Climb (website)

Static pages for the App Store listing, ready for GitHub Pages.

| Page | App Store Connect field |
| --- | --- |
| `marketing.html` | Marketing URL |
| `support.html` | Support URL |
| `privacy.html` | Privacy Policy URL |

## Before publishing

1. Support email is set to `pokobuilder@zohomail.eu` in `support.html` and `privacy.html`.
2. Check the publisher name ("Munnie") in the footers and privacy policy.
3. After release, set the App Store link on the button in `marketing.html`.

## GitHub Pages

Push to a public repo, then Settings → Pages → Deploy from branch → `main` / root.
URLs will be `https://<user>.github.io/<repo>/support.html` etc.
